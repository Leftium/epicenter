Canonical editor callers

Experimental evidence, not a production API. One canonical editor for a todo row, shared by a vanilla DOM view, a Solid view, and a Svelte 5 view. The editor's draft is the row's fields and body; a save writes the whole row in canonical form.

The folder is an in-memory test harness in this page, not a persistent backend. Its files disappear on reload or reset. "Another program" and the reply gates simulate what a real folder can meet.
