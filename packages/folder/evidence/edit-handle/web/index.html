Edit handle experiment

Experimental evidence, not a production API. Question under test: can one framework-neutral edit handle serve vanilla, Solid, and Svelte callers while keeping saved-file facts honest under concurrent writers?

Disposable folder: connecting…. Saves and the other writer change only that folder's files. The caller sources shown below are read from this checkout, never written.

Each panel edits todos/plan.md through the same handle. Typing in any panel changes the one draft all three show. Nothing saves until you press Save, unless you turn on autosave beside the shared handle. One handle edits one file: its fields, body, and raw source. It is not a transaction across files.
