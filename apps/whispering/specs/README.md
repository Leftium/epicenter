# Whispering specs

Every spec in this directory predates the standalone file-folder app. They
describe the earlier Whispering: its Yjs store, its `#platform/*` service
leaves, its shortcut and transcription-provider layers, and native recorder and
decoder work that now lives in `apps/epicenter/src-tauri`.

None of them is current guidance for the code in `apps/whispering`. Read
[README.md](../README.md) and [ARCHITECTURE.md](../ARCHITECTURE.md) for that.
Delete a spec here when its subject is settled or gone; Git keeps the text.
